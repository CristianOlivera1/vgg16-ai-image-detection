Conectando…

¿Real o generada por IA?

Sube una o varias imágenes y el modelo VGG16 entrenado con CIFAKE las clasificará al instante.

No se pudo conectar con el servidor. Desde la carpeta raíz del proyecto ejecuta python -m app.server y abre http://127.0.0.1:8000.

    El modelo se entrenó con imágenes de 32×32 px. Con fotos grandes o muy procesadas el resultado puede ser menos fiable.
